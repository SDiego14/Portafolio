# Portafolio Profesional - Diego Fernando Solís Rojas 🇦🇷

Este es mi portafolio profesional desarrollado con **React.js**. El sitio está diseñado para presentar mi perfil híbrido, combinando mi formación en **Gestión de la Administración Central** con mis estudios avanzados en **Sistemas de Información**.

## 🚀 Tecnologías Utilizadas

* **Frontend:** React.js, HTML5, CSS3 (Diseño Responsive).
* **Interactividad:** React Hooks (`useState`, `useEffect`).
* **Integraciones:** [EmailJS](https://www.emailjs.com/) para el formulario de contacto dinámico.
* **Despliegue:** (Aquí puedes poner Vercel, Netlify o GitHub Pages si ya lo subiste).

## 📋 Características

- **Diseño Institucional:** Estética limpia y profesional orientada al sector administrativo y tecnológico.
- **Timeline de Trayectoria:** Visualización de mi experiencia laboral desde 2018 hasta la actualidad.
- **Galería de Títulos:** Modal interactivo para visualizar mi título de Técnico emitido por la UNNE.
- **Formulario de Contacto:** Conexión directa a través de API para recepción de consultas por email.
- **Habilidades Interactivas:** Tarjetas con efectos hover para mostrar especialidades técnicas.
